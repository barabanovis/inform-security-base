# Основы информационной безопасности

## Лабораторная №3 "Построение гибридной криптосистемы"

Результат данной лабораторной работы - гибридная криптосистема - будет сочетать в себе преимущества симметричных и асимметричных алгоритмов шифрования и в целом даже напоминать системы, использующиеся на практике.

Работать она будет следующим образом: сообщение шифруется при помощи симметричного алгоритма, а ключ симметричного алгоритма - ассиметричным. В качестве асимметричного алгоритма будет использоваться RSA, симметричный алгорим выбирается в соответствии с вариантом.

Требования к функционалу реализуемого софта, варианты заданий, теоретическая справка и примеры кода приведены в [ноутбуке](https://github.com/itsecd/isb-2026/blob/main/docs/ISB_Lab3.ipynb).

# Отчет о проделанной работе

## Написание программы

Процесс разработки данного ПО можно разделить на 5 основных пунктов, каждому из которых соответствует файл.

1. Общий интерфейс консольной версии приложения [`hybrid_cryptosystem.py`](hybrid_cryptosystem.py)
   - Парсинг аргументов командной строки в функции `argument_parsing()`
   - Чтение файла [`settings.json`](settings.json)
   - Выбор соответсвующего режима работы приложения в функции `main`
1. Алгоритм генерации ключей [`key_generation.py`](modules_folder/key_generation.py)
   - Генерация симметричного ключа в фукнции `symmetric_key_generate()` и сохранение его в файл в соответствии c `settings.json`
   - Генерация ассиметричного ключа: публичного и приватного в функции `asymmetric_key_generate()` и сохранение обоих в файлы
1. Шифрование текста [`encryption.py`](modules_folder/encryption.py)
   - Чтение симметричного ключа из файла `read_symmetric_key_from_pem(filepath)`
   - Чтение текста из файлов `fileworking.read_text(filepath)`
   - **Паддинг текста для возможности его последующего шифрования `text_padding(text)`**
   - Сохранение зашифрованного текста в бинарный файл `fileworking.save_binary(c_text, filepath)`
1. Дешифрование текста [`decryption.py`](modules_folder/decryption.py)
   - Десериализация ключей (чтение их из бинарных файлов)
   - Дешифрование симметричного ключа ассиметричным алгоритмом `assym_decryption(secret_key, private_key)`
   - Дешифрование текста симметричным алогоритмом `symm_text_decryption(c_text, symm_key)`
   - Непосредственно запись дешифрованного текста в файл `fileworking.write_text(json_data['decrypted_file'], dc_text)`
1. Графическая пользовательская оболочка [`hybr_crsys_qt.py`](hybr_crsys_qt.py)  
   Польностью написана при помощи нейронной сети DeepSeek. Достаточно проста в понимании и практична для прикладных задач.  
   Специально обеспечена возможность перенастройки страндартных путей сохранения для удобства пользователя.

## Как пользоваться консольной версией?

- `hybrid_cryptosystem.py` -- консольное приложение
- `py hybrid_cryptosystem.py -gen` -- генерация ключей
- `py hybrid_cryptosystem.py -enc` -- шифрование
- `py hybrid_cryptosystem.py -dec` -- дешифрование
